A Function Is a Rule from Inputs to Outputs

Goal for this lesson: explain "A Function Is a Rule from Inputs to Outputs" in your own words, then complete the transfer exercise below on your own.

Prerequisites: The four arithmetic operations; beginners can start here. Try the worked example first; if the notation feels heavy, go back to the preparation module.

Intuition First, Then Symbols

A function assigns to each input in its domain exactly one output. The domain is not decoration: for f(x)=1/x over the reals, 0 must be excluded. The graph places inputs horizontally and outputs vertically, which makes the behavior easy to inspect.

A Derivation, Step by Step

For f(x)=2x+1, the input 3 gives 7. Asking which input produces the output 7 means solving 2x+1=7, which gives 3. Evaluating a function and solving an equation are the two directions of one and the same question.

Pause and Try It

For f(x)=x², what is f(−2)? Does the output 4 come from only one input?

Show the solution and self-check criteria

f(−2)=4; the input 2 also gives 4. Each input has a unique output, but that does not mean each output comes from only one input.

Self-check: Is the conclusion correct? Are the conditions stated? Can you explain the key steps without looking at the example? If you only recalled the answer, redo the lesson.
