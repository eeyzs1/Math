Notation and Methods: Quick Reference

∀ / ∃

For all / there exists; swapping the order of the quantifiers can change the proposition.

⇒ / ⇔

Implies / is equivalent to; the converse of an implication does not hold automatically.

∈ / ⊆

An element belongs to a set / one set is contained in another.

∅

The empty set; it contains no elements and is a subset of every set.

∪ / ∩ / ∖

Union, intersection, difference; counting a union requires subtracting the overlap (inclusion–exclusion).

f: A → B

A function with domain A and codomain B; the values actually taken form the image.

lim / f′ / ∫

Limit / derivative / integral; check the existence conditions before using them.

ε-δ

The precise language of limits: for every ε>0 there is a δ>0; ε comes first, then δ.

dy/dx vs y″

Derivative notation: dy/dx stresses the "limit of difference quotients"; y″ is the second derivative (the derivative of the derivative).

∂ / ∇

Partial derivative (freeze the other variables and differentiate one) / gradient (the vector of partial derivatives, pointing in the direction of steepest ascent).

Σ / Π

Sum / product; watch the starting index — Σ from n=0 and Σ from n=1 are different sums.

∞

Infinity; "tends to ∞" is shorthand for "grows beyond every bound" — ∞ is not a real number.

ℕ / ℤ / ℚ / ℝ / ℂ

The sets of natural numbers / integers / rationals / reals / complex numbers; before saying "no solution", ask in which set.

≡ (mod m)

Congruence: m divides the difference of the two numbers; the standard example of an equivalence relation and a quotient set.

⌊x⌋ / ⌈x⌉

Floor / ceiling; workhorse tools for step counting and divisibility counting.

|x|

Absolute value; distance on the number line, and a signal to argue by cases.

ker / im

The kernel (inputs mapped to zero) and the image (all outputs) of a linear map; the rank–nullity theorem relates the two.

det / tr

Determinant (the area/volume scaling factor) / trace (the sum of the diagonal entries, equal to the sum of the eigenvalues).

Aᵀ

Transpose; the inner product can be written uᵀv, and the least-squares normal equations are AᵀAx=Aᵀb.

Av=λv

Eigenvalue λ and nonzero eigenvector v: the spanned line is preserved; negative λ reverses direction and λ=0 maps v to zero.

‖u‖ / u·v

Norm (length √(u·u)) / inner product; a zero inner product means perpendicular.

O(·)

Asymptotic upper bound; when the input doubles, watch by what factor the leading term grows.

sup / inf

Supremum / infimum; the core statement of the completeness of the real numbers.

max / min / argmax

Maximum and minimum values / the input position at which the maximum is attained.

E[X] / Var / Cov

Expectation (a probability-weighted average) / variance / covariance; linearity of expectation requires no independence.

P(A|B)

The probability of A given that B occurred; requires P(B)>0.

X ~ N(μ,σ²)

The random variable X follows a normal distribution with parameters μ and σ²; read "~" as "is distributed as".

H(X)

Entropy: the average number of bits of uncertainty in a random variable.

H₀ / p-value

Null hypothesis / the probability, if H₀ is true, of data at least this extreme; a p-value is not the probability that H₀ is true.

R²

Coefficient of determination: the share of the variance explained by a regression; a high R² does not imply causation.

κ(A)

Condition number: the worst-case amplification from relative input error to relative output error.

χ(G)

Chromatic number of a graph: the fewest colors needed so that adjacent vertices get different colors.

φ(n)

Euler's totient function: the count of integers in 1..n coprime to n; a key parameter of RSA.

⊕ / ⊗

Direct sum / tensor product: ways to "put spaces together" or "multiply spaces".

Vector / matrix

A vector records data or a direction; a matrix represents a linear map in given bases.

Definition / theorem / conjecture

A convention fixing what a term means / a result proven from assumptions / a judgment awaiting proof or refutation.

Example / counterexample

Examples build understanding; a counterexample can refute a universal statement, and finitely many confirming examples usually cannot prove one.
