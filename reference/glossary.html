数学符号与方法速查

∀ / ∃

对所有 / 至少存在一个；交换量词顺序可能改变命题。

⇒ / ⇔

推出 / 等价；逆命题不自动成立。

∈ / ⊆

元素属于集合 / 集合包含于集合。

∅

空集；不含任何元素，是任何集合的子集。

∪ / ∩ / ∖

并、交、差；并集计数要减重叠（容斥原理）。

f: A → B

定义域为A、陪域为B的函数；实际取到的值组成像集。

lim / f′ / ∫

极限 / 导数 / 积分；使用前先检查存在条件。

ε-δ

极限的精确语言：任给 ε>0，能找到 δ>0；先给 ε 再找 δ。

dy/dx 与 y″

导数的记号：dy/dx 强调“差商的极限”，y″ 是二阶导（导数的导数）。

∂ / ∇

偏导数（冻结其他变量对某一个求导）/ 梯度（各偏导组成的向量，指向上升最快方向）。

Σ / Π

求和 / 求积；注意起点：Σ 从 n=0 还是从 n=1 起，结果不同。

∞

无穷；“趋于 ∞”是“任意大”的简写，∞ 不是实数。

ℕ / ℤ / ℚ / ℝ / ℂ

自然数 / 整数 / 有理数 / 实数 / 复数集；说“无解”前先问在哪个集合里。

≡ (mod m)

同余：m 整除两数之差；等价关系与商集的标准例子。

⌊x⌋ / ⌈x⌉

下取整 / 上取整；步进计数与整除计数的常用工具。

|x|

绝对值；数轴距离，也是分段讨论的信号。

ker / im

线性映射的核（映到零的输入）与像（全部输出）；秩零化度定理连接两者。

det / tr

行列式（面积/体积倍率）/ 迹（对角元之和，等于特征值之和）。

Aᵀ

转置；内积可写成 uᵀv，最小二乘的正规方程是 AᵀAx=Aᵀb。

Av=λv

特征值 λ 与特征向量 v：方向不变、只按 λ 缩放。

‖u‖ / u·v

范数（长度 √(u·u)）/ 内积；内积为零即垂直。

O(·)

渐近上界；输入翻倍时看主导项变几倍。

sup / inf

上确界 / 下确界；实数完备性的核心表述。

max / min / argmax

最大最小值 / 取到最大值的输入位置。

E[X] / Var / Cov

期望（概率加权平均）/ 方差 / 协方差；期望的线性性不需要独立性。

P(A|B)

在B发生条件下A的概率，要求P(B)>0。

X ~ N(μ,σ²)

随机变量服从参数 μ、σ² 的正态分布；~ 读作“服从分布”。

H(X)

熵：随机变量不确定性的平均比特数。

H₀ / p 值

原假设 / “若 H₀ 为真，出现这般极端数据”的概率；p 值不是 H₀ 为真的概率。

R²

决定系数：回归解释的方差占比；高 R² 不等于因果。

κ(A)

条件数：输入相对误差到输出相对误差的最大放大率。

χ(G)

图的着色数：相邻顶点不同色所需的最少颜色数。

φ(n)

Euler 函数：1..n 中与 n 互素的个数；RSA 的关键参数。

⊕ / ⊗

直和 / 张量积：把空间“拼起来”或“乘起来”。

向量 / 矩阵

向量描述数据或方向；矩阵表示给定基下的线性映射。

定义 / 定理 / 猜想

术语约定 / 已由假设证明的结论 / 待证明或推翻的判断。

例子 / 反例

例子帮助理解；反例可推翻全称命题，有限个正例通常不能证明全称命题。
