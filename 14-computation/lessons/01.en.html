Theoretical Computer Science and Information Mathematics / LESSON 01

Algorithmic Complexity Is About Growth

Goal for this lesson: explain "Algorithmic Complexity Is About Growth" in your own words, then complete the transfer exercise below on your own.

Prerequisites: Logic, combinatorics, and probability. Try the worked example first; if the notation feels heavy, go back to the preparation module.

Intuition First, Then Symbols

Complexity describes how resource use grows as the input size grows. O(n) is an asymptotic upper bound, not an exact number of seconds; when analyzing an algorithm, say whether the worst case, the average case, or some other scenario is meant.

A Derivation, Step by Step

Binary search on a sorted array halves the pool of candidates at each step. For n=1024, about 10 halvings leave a single item, exhibiting logarithmic growth; searching an unsorted array item by item must, in the worst case, examine all n items.

Pause and Try It

When the input size doubles, by roughly what factor does the dominant work of a linear algorithm and of a quadratic algorithm grow?

Show the solution and self-check criteria

About 2× and 4×, respectively, provided one compares dominant terms at sufficiently large sizes. Actual running times are also affected by constants, hardware, and the input.
