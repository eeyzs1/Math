多项式除法与余式定理

本课目标：用自己的话解释“多项式除法与余式定理”，并独立完成下方迁移题。

先修：分数、等式与基础证明。先试读例题；若符号吃力，回到预备知识。

先理解，再写符号

多项式带余除法与整数一样：f(x)=(x−c)q(x)+r，余式 r 是常数。余式定理：r=f(c)——代入即得余数。于是 c 是根当且仅当 (x−c) 整除 f；归纳剥因子可证 n 次多项式至多 n 个根。“至多 n 个根”针对域（如 R、C）上的非零 n 次多项式；零多项式与有零因子的系数环不能直接套用。

一步步推导

f(x)=x³−3x+2 除以 x−1：x³−3x+2=(x−1)(x²+x−2)=(x−1)²(x+1)。f(1)=1−3+2=0 与余式 0 一致，1 还是二重根。

停下来试一试

用余式定理求 x⁴−x+1 除以 x+1 的余数，并判断 x+1 是否为因子。

查看解析与自评标准

r=f(−1)=1+1+1=3≠0，x+1 不是因子。代入求余数比长除法快——余式定理把“除法问题”变成“求值问题”，这正是“根与因子”之间的桥。
