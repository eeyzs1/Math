Differential Equations and Dynamical Systems / LESSON 03

Direction Fields and Initial Value Problems

Goal for this lesson: explain "Direction Fields and Initial Value Problems" in your own words, then complete the transfer exercise below on your own.

Prerequisites: Derivatives and integrals; Lesson 7 on the phase plane requires linear algebra (eigenvalues: see 04, Lesson 07). Try the worked example first; if the notation feels heavy, go back to the preparation module.

Intuition First, Then Symbols

A first-order equation y′=f(t,y) assigns a slope to each point (t,y); drawing these little line segments produces the direction field, and a solution curve is a curve that fits the direction field everywhere. The initial value y(t₀)=y₀ sets the starting point. When f and ∂f/∂y (differentiate with respect to y, treating t as a constant; partial derivatives: see 06, Lesson 09) are continuous, the solution exists and is unique locally — exactly one solution curve passes through each point.

A Derivation, Step by Step

y′=−2y: the higher up, the more steeply the segments point downward, and in the solution family y=Ce⁻²ᵗ the curves for different C never intersect. If two solution curves both passed through the same point, they would be two solutions of the same initial value problem, contradicting existence and uniqueness, so they must be the same curve — the fact that "each point has only one slope" is not by itself enough to rule out two curves meeting tangentially. Advancing step by step along the direction field is Euler's method: see 12, Lesson 03.

Pause and Try It

Why can a solution of y′=y² run away in finite time? Does this contradict existence and uniqueness?

Show the solution and self-check criteria

The solution starting from y(0)=1 is y=1/(1−t), which tends to infinity at t=1 (blow-up in finite time). Existence and uniqueness is a local guarantee: a solution can escape the region under discussion in finite time, so it has to be examined interval by interval.
