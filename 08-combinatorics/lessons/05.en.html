Combinatorics and Graph Theory / LESSON 05

Trees and Connectivity

Goal for this lesson: explain "Trees and Connectivity" in your own words, then complete the transfer exercise below on your own.

Prerequisites: Integers and basic proof. Try the worked example first; if the notation feels heavy, go back to the preparation module.

Intuition First, Then Symbols

A tree is a connected acyclic graph; equivalent characterizations: a tree on n vertices has exactly n−1 edges; there is exactly one path between any two vertices; adding one more edge creates a unique cycle. Every connected graph has a spanning tree (cycle-breaking: while a cycle exists, delete one of its edges — connectivity survives).

A Derivation, Step by Step

Four cities need only 3 edges to be fully connected — that is a spanning tree; any extra edge merely creates a redundant loop. Each cycle-breaking deletion keeps the graph connected and lowers the edge count by one, and the process terminates at a tree.

Pause and Try It

At least how many edges must a connected graph on 5 vertices have? What is its shape when it has exactly that many?

Show the solution and self-check criteria

At least 4. A connected graph with exactly 4 edges must be a tree: if it contained a cycle, deleting one edge of that cycle would leave it connected with only 3 edges, contradicting 'at least 4 to be connected'. The edge count n−1 draws the boundary of the trees precisely.
