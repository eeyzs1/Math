Topology / LESSON 01

Open Sets and the Topological Definition of Continuity

Goal for this lesson: explain "Open Sets and the Topological Definition of Continuity" in your own words, then complete the transfer exercise below on your own.

Prerequisites: sets, maps; advanced topics require analysis and algebra. Try the worked example first; if the notation feels heavy, go back to the preparation module.

Intuition First, Then Symbols

In a metric space, every point of an open set carries an entire small ball that still stays inside the set, as with the open interval (0,1); a closed set contains its own boundary. Continuity can be restated without mentioning distance: the preimage of every open set is open. This reformulation detaches "continuous" from any particular distance and makes it the starting point of topology.

A Derivation, Step by Step

f(x)=1/x is continuous on (0,∞): the preimage of the target open set (1,2) is (1/2,1), again open. Conversely, a jump function takes one side's value at the jump point; choose an open set straddling the jumped value, and its preimage cuts out the jump point together with half a side, so it is no longer open.

Pause and Try It

Using "the preimage of an open set is open", explain why a step function is discontinuous at its jump point.

Show the solution and self-check criteria

Suppose the values on the two sides of the jump are 0 and 1, and the function takes the value 1. Take the open set (1/2,3/2): its preimage contains the jump point and a stretch to its right, yet omits every point on the left however close to the jump. The preimage is "torn" at the jump point, hence not an open set, and the function is discontinuous.
